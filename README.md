# Подготовка к личностям

Интерактивный сайт для подготовки по 22 историческим личностям.

## Возможности

- **Список** — все личности с поиском, клик открывает полное описание
- **Карточки** — повторение материала (показать / скрыть ответы)
- **Викторина** — по полному описанию выбираешь, кто это (4 варианта, порядок каждый раз разный)

Материал строго по исходному файлу.

## Как открыть локально

Просто открой `index.html` в любом браузере.

## GitHub Pages

1. Создай новый репозиторий на GitHub
2. Загрузи файлы `index.html` и `README.md`
3. Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save
4. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<твой-username>.github.io/<имя-репозитория>/`
